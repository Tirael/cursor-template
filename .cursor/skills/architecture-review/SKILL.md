# Architecture Review (Skill)

## Когда применять

- Перед слиянием больших изменений
- Перед релизом
- При появлении новых интеграций или новых bounded contexts

## Чек-лист

- Границы контекстов чёткие, нет прямых зависимостей на чужие БД.
- NFR соблюдаются, измеримость подтверждена.
- Безопасность: OIDC, ABAC, Vault, TLS/mTLS, аудит.
- Интеграции: outbox для событий, идемпотентность обработчиков.
- Наблюдаемость: логи/метрики/трейсы, health endpoints, алерты.
- Длительные операции вынесены в асинхронные job’ы.
