# C4 Modeling (Skill)

## Когда применять

- Уточняем контекст и границы системы
- Проектируем контейнеры и связи
- Детализируем компонентный уровень для ключевых контейнеров

## Где хранить артефакты

- C4/LikeC4: `src/c4/`
- Экспорт PNG: `png/` (см. skill `export-likec4-png-white`)

## Правила моделирования

- Один элемент = одно назначение, не смешивать роли.
- Связи подписывать как “зачем” + протокол.
- View не должен дублировать модель: только “срез” по цели.
- Изменения сопровождаются обновлением `version`/`lastUpdated` в документах.
