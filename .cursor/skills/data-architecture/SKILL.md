# Data Architecture (Skill)

## Когда применять

- Проектируем хранение данных по bounded contexts
- Выбираем консистентность и стратегии кэша
- Планируем поиск и индексацию

## Правила

- Database per Service: нет прямых запросов в чужие БД.
- Контрактные данные наружу — только через API или события.
- Миграции версионируются и применяются автоматически.
- Cache-aside для чтений, инвалидация по событиям.
- Поиск: отдельный индекс, асинхронное обновление, reindex как job.
