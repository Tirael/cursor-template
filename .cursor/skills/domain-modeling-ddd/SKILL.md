# Domain Modeling (DDD) (Skill)

## Когда применять

- Выделяем bounded contexts и их контракт
- Проектируем агрегаты и инварианты
- Определяем доменные события и интеграционные события

## Минимальные правила

- Границы bounded context фиксировать явно и не размывать “общими” моделями.
- Агрегат — единица транзакционной целостности.
- Инварианты проверяются внутри агрегата, а не “снаружи”.
- События:
  - Доменные — внутри контекста.
  - Интеграционные — на границе и только через outbox.
