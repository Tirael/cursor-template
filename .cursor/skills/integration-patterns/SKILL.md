# Integration Patterns (Skill)

## Когда применять

- Проектируем взаимодействия между bounded contexts
- Выбираем sync (gRPC) vs async (Kafka)
- Определяем контракты и версионирование сообщений

## Правила

- Синхронно: только когда нужен немедленный ответ.
- Асинхронно: события, длительные операции, интеграции.
- Идемпотентность обработчиков обязательна.
- Публикация Integration Events только через Transactional Outbox.
- Контракты версионировать и не ломать обратно совместимость.
