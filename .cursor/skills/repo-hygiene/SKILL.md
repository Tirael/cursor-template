# Repo Hygiene (Skill)

## Когда применять

- Перед публикацией шаблона в GitHub
- После перемещения папок (`src/c4`, `src/scripts`, `src/examples`)
- После чистки/рефакторинга документации

## Чек-лист

- Все инструкции и пути согласованы с SSOT (`canonical-sources.md`).
- Нет битых ссылок на удалённые файлы/папки.
- C4 диаграммы живут только в `src/c4/`.
- PlantUML диаграммы живут только в `src/diagrams/`.
- Скрипты репозитория живут только в `src/scripts/`.
- Примеры проектов и кода живут только в `src/examples/`.
- Нет дублей документов “про одно и то же”.

## Быстрые проверки

- Прогон markdownlint по всему репозиторию.
- Поиск по репозиторию на старые пути: `src/README.md`, `scripts/`, `src/model`.
