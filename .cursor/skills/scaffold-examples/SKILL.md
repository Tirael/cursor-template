# Scaffold Examples (Skill)

## Где храним

- Все примеры: `src/examples/`

## Рекомендованная структура

```text
src/examples/
  dotnet/
  angular/
  python/
```

## Правила

- Каждый пример самодостаточен и имеет свой `README.md`.
- Минимум зависимостей, максимум повторяемости запуска.
- Примеры не должны тянуть доменную документацию — только демонстрация техники.
