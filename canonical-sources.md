# Канонические источники и ссылки (SSOT) (v1.0)

## Назначение

Этот документ — **единое место сопровождения** ссылок на канонические источники
и внутренних путей, которые нежелательно размазывать по остальным документам.

## Приоритет информации

- **Core (обязательные правила, SSOT)**:
  - `.cursor/rules/nfr-core.mdc` (v1.0, lastUpdated: 2026-02-04)
  - `.cursor/rules/project-core.mdc` (v1.0, lastUpdated: 2026-02-04)
- **Reference**:
  - `nfr-requirements.md` (v1.0, lastUpdated: 2026-02-04)

Если какой-либо документ расходится с Core — **Core имеет приоритет**.

## Каноничные пути (SSOT)

- C4/LikeC4: `src/c4/`
- PlantUML (диаграммы последовательностей и пр.): `src/diagrams/`
- Скрипты: `src/scripts/`
- Примеры проектов/кода: `src/examples/`
- Экспорт PNG: `png/`
- Чек‑листы: `checklists/`

## Правило сопровождения

- Все ссылки на `.cursor/...` должны жить **только здесь**.
- В остальных документах вместо прямых ссылок на `.cursor/...` использовать
  ссылку на этот файл: `canonical-sources.md`.
