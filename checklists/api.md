# Чек‑лист API (v1.0)

- **Контракты**: schema-first, версия в контракте, обратная совместимость.
- **Идемпотентность**: команды с `Idempotency-Key`/`correlationId`.
- **Валидация**: входные DTO валидируются на границе.
- **Ошибки**: единый формат ошибок, отсутствие утечек чувствительных данных.
- **Таймауты**: фиксированы и согласованы между клиентом и сервером.
- **Ретраи**: только на безопасных операциях, с backoff.
- **Рейт‑лимиты**: per IP / per user / per tenant / per endpoint.
- **Аутентификация/авторизация**: OIDC + ABAC, tenant isolation.
- **Наблюдаемость**: `correlationId`/`tenantId` в логах, метрики p95/p99.
