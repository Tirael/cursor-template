# Чек‑лист DB (v1.0)

- **Границы**: Database per Service, запрет прямого доступа к чужим БД.
- **Модель данных**: ключи, ограничения, уникальности, жизненный цикл сущностей.
- **Индексы**: есть для критичных запросов, проверены планом выполнения.
- **Транзакции**: граница агрегата, уровень изоляции, блокировки.
- **Read-after-write**: правило чтения из primary, если нужно.
- **Миграции**: версионирование, автоматика применения, обратимость где возможно.
- **Репликация/резерв**: RPO/RTO понятны и проверяемы.
- **Шардирование**: ключ шардирования, влияние на запросы и миграции.
- **Кэш**: что кэшируем, TTL, инвалидация, защита от stampede.
